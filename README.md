# Redo_sass

Förnyat UI/UX för Altavistas hemsida. Utgått från hur den såg ut under 90-talet:
https://www.webdesignmuseum.org/gallery/altavista-1996

Tagit bort "plottrig" text. Lagt till en footer med länkar till mer specifika saker. Använd icons och text för tydlighet. 
Använt färgerna koncist, i den tidigare versionen var färger blandade hur som helst. Använt färger utifrån loggan. Hittade inte den gamla loggan så tog den jag hittade först.
Lagt till en header där man kan välja språk, andra inställningar och ha en egen profil.
